# Private Gallery interface

F4 presentation uses the owner HTTP contract in `../docs/runtime/ARTIFACTS.md`. It creates persisted selections from current Photos metadata or an exact current trip revision. Empty owner-authored galleries are allowed. There is no publication, plugin execution, HTML renderer or automatic membership expansion.

The Artifacts destination lists bounded pages of saved galleries. Create selects Photos in twelve-record pages with an optional known-local-day filter, or selects a current trip snapshot. Edit supports title, grid/story layout, ordered members, cover, explicit add/remove and re-inclusion. The saved view renders safe typed text and original capture offsets; each member opens the existing authenticated private media viewer. Missing copies remain honestly metadata-only. Unknown offsets do not become fabricated capture days. Gallery Debug reads real retained operation receipts. Recompose preserves exclusions and prior members; it uses its own explicit form and current expected revision.

All mutations use the owner cookie, CSRF and same-origin JSON endpoints. The exact key and payload remain in live memory for retry after network/503 failure. No answer, selection or draft is placed in URLs or browser storage. A409 clears prior content and requires an explicit current refresh;403/404 also clear title, members, composer and diagnostic output. Reads clear previous output before loading;401 clears the owner session. Opening media rechecks the complete Gallery first. A media refusal clears its parent Gallery as well. Existing viewer behavior for Photos is unchanged; an optional failure callback is used only by the Gallery. Unmount and route/session changes abort active work.

Frontend API path validation adds only exact32hex Artifact detail/debug/edit/recompose forms. No server URL is accepted. Gallery capacity and source restrictions remain authoritative on Python; UI limits a manual selection to200 members and reports capacity errors. Explicit hidden Photos may be selected only when returned by current policy; trip and automatic recompose candidates follow the backend's stricter Hidden exclusion.
